# Monero Event Study Analysis

## SSRN Research Publication

This repository contains the implementation, research paper, and supporting materials for the SSRN-style research publication:

### “Regulatory Shocks, Exchange Delistings, and Volatility Dynamics in Privacy Coins: An Event Study Analysis on Monero (XMR)”

---

## Project Overview

This research investigates how cryptocurrency regulations and exchange delisting announcements affect Monero (XMR) using event-study methodology and financial econometrics.

The study evaluates:

* Abnormal Returns (AR)
* Cumulative Abnormal Returns (CAR)
* Rolling Volatility
* Regulatory Shock Impact
* Liquidity-Driven Market Instability

## Methodology

The paper applies a standard event-study framework using:

* Estimation Window
* Event Window
* Mean-Adjusted Return Model
* Abnormal Return Analysis
* Rolling Volatility Modeling
